Как обратиться к HTTP API:
{{- if .Values.ingress.enabled }}

  1. Через Ingress (добавьте хост в /etc/hosts, IP берётся из `minikube ip`):
{{- range .Values.ingress.hosts }}
{{- $host := .host }}
{{- range .paths }}
     http{{ if $.Values.ingress.tls }}s{{ end }}://{{ $host }}{{ .path }}
{{- end }}
{{- end }}
{{- end }}

  2. Через port-forward:

     kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "calendar.fullname" . }}-api 8888:{{ .Values.calendar.service.httpPort }}
     curl "http://localhost:8888/events/day?userID=1&date=$(date -u +%Y-%m-%dT%H:%M:%SZ)"

Статус миграций:

  kubectl --namespace {{ .Release.Namespace }} logs job/{{ include "calendar.fullname" . }}-migrate
